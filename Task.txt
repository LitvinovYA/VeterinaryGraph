Задание: Ветеринария — Питомцы, владельцы, прививки

Графовая база данных в MS SQL Server

Тема: Ветеринарная клиника

Узлы (Nodes):
1. Owners (Владельцы) — владельцы домашних животных
2. Pets (Питомцы) — домашние животные
3. Vaccinations (Прививки) — виды вакцин
4. Vets (Ветеринары) — ветеринарные врачи

Рёбра (Edges):
1. Owns (Владеет) — связь "владелец владеет питомцем" (Owner -> Pet)
2. Vaccinated (Вакцинирован) — связь "питомец привит вакциной" (Pet -> Vaccination)
3. PerformedBy (Проведена) — связь "прививку сделал врач" (Vaccination -> Vet)
4. Referral (Направление) — связь "врач направил владельца" (Vet -> Owner)

Запросы:
- MATCH: 5 различных запросов с цепочками из 3+ узлов
- SHORTEST_PATH: 2 запроса (шаблоны "+" и "{1,n}") с LAST_NODE и STRING_AGG

Диаграммы в drawio на отдельных страницах:
1. Схема узлов и рёбер
2. Данные таблицы Owners (10+ строк)
3. Данные таблицы Pets (10+ строк)
4. Данные таблицы Vaccinations (10+ строк)
5. Данные таблицы Vets (10+ строк)
6. Данные таблиц рёбер
7. Итоговый граф со связями

Визуализация в Power BI с Force-Directed Graph.
